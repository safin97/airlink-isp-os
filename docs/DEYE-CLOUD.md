# Deye Solar

Only the owner can configure Deye Solar. Open **Deye Solar** and connect using your Deye Cloud app account (email, username, or mobile number with country code). Select the same region as the Deye app: Europe/EMEA/Asia-Pacific, Americas, or India. Deye OpenAPI also requires an **App ID and App Secret** from [Deye's developer portal](https://developer.deyecloud.com/) with station monitoring permission. A normal app login alone does not supply these developer credentials. An optional company ID selects a business organization; otherwise the personal account is used.

Select a station to view solar production, battery state of charge and power, load consumption, grid power, and separate charging/discharging and import/export readings when supplied by Deye. The dashboard reads station-level totals. It does not configure or control the inverter. Missing, malformed and unsupported measurements display as unavailable, while actual zero readings remain zero. When every inverter supplies fresh `BatteryPower` or `TotalGridPower` measurements with W/kW units, those device totals take priority over incomplete or ambiguous station fields. Deye inverter battery power is positive for discharge and negative for charging; grid power is positive for import and negative for export. Each direction is summed separately across inverters. Partial, stale, offline, duplicate or unsupported-unit device readings are not used as station totals. Without complete device readings, the original station fields remain available and incomplete directions remain unknown. An unpaired station `wirePower` is not labeled as export because some stations use it for signed grid exchange. The API records measurement sources and timestamps.

The main **Dashboard** includes a compact Deye Solar overview for accounts with both Dashboard and Deye Solar access. Small solar, battery, grid and load nodes connect to a central inverter with bridge lines, with their live power readings and battery charge bar. The dashboard card shows only these five components; station selection, cloud status, refresh controls and grid history are in the Deye Solar section. Hover or long-press the dashboard diagram for the latest cloud timestamp or a connection error. Battery power and charging/discharging/idle status are shown, with grid import/export power. The Grid component includes green **On-grid**, amber **Off-grid**, or gray **Unknown** status. Known states are explicitly labeled **Voltage estimate**: voltage presence/absence does not confirm the inverter’s configured operating mode or grid relay position. Off-grid and unknown grid links are dashed and do not show flow arrows; solar, battery and load remain visible. Zero grid power and a cloud-offline logger do not determine grid status. Arrows use positive solar/load power and unambiguous charge/discharge or import/export fields from recent cloud readings; missing, conflicting or stale direction data has no arrow. Flow markers move continuously along active dashboard connections using the latest recent readings: solar → inverter, inverter → battery when charging, battery → inverter when discharging, and inverter → load. Motion stops for zero, missing, conflicting or stale flow data, respects reduced-motion settings, and pauses when the view is inactive. Animation represents the last reported flow; it does not imply second-by-second measurements or identify which source supplies a particular load. Open **Deye Solar** from the navigation menu for the detailed view. Both layouts adapt to phones and support light/dark themes. An unconnected account sees a setup prompt without fabricated readings; connection setup remains in the Deye Solar section. Revoking Deye Solar access also removes the dashboard overview and stops its refresh timer.

The **Load** component shows watts (**W**) and current (**A**). A supported load-current reading takes priority. For a single inverter exposing one supported load-voltage output, current can be estimated from the same sample's `TotalConsumptionPower ÷ LoadVoltage`; it is labeled **Est.** with a tooltip explaining the one-output, power-factor-1 assumption. Actual RMS amperes can differ. Inverter AC current and battery current are never substituted for load current. Multiple inverters, known additional phases, invalid or missing measurements display **Amps unavailable** rather than a misleading zero or a sum of amperages. Load watts remain in W even above 1000 W. Current updates through the existing live stream and cache without extra cloud requests.

To choose the station shown on the dashboard, open **Deye Solar**, choose a **Power station** (use the page arrows if needed), and select **Show this station on dashboard**. The choice is saved per owner connection and is shared with authorized viewers and survives reloads and server restarts. Browsing another station does not change the saved dashboard choice. **Use first station automatically** clears the preference. Only the owner can change the saved dashboard station; shared viewers can browse readings without changing it. The dashboard picks up preference changes through the live stream or a quiet fallback update if the live connection drops. If a selected station becomes unavailable, it shows an error instead of silently switching to another station. Changing the Deye account, region or application clears the preference; reconnecting the same account preserves it.

AirLink monitors each active owner’s saved dashboard station (or the first station automatically) in the background, targeting a cloud check every 5 seconds. The API service must be running; a slow cloud request or several busy accounts can delay a poll. Authenticated live connections receive updated cached readings within the next two-second live frame, without making extra cloud calls. Healthy live views do not periodically reload over HTTP. If the stream disconnects or stops delivering heartbeats for 10 seconds, a quiet five-second fallback updates the existing diagram without clearing readings or showing a loading bar. The stream reconnects automatically. The detailed view uses the same quiet polling for stations other than the background-monitored dashboard station. Other stations are polled only while viewed. Reading responses are cached per owner connection and station for five seconds, with temporary failures cached for 30 seconds to avoid rapid retry loops (up to eight stations, retaining the dashboard selection); station lists remain cached for three minutes. The cloud observation time is shown, with readings older than 15 minutes marked stale and missing/ambiguous timestamps marked unknown. Refreshing cannot make the inverter upload faster. Station power fields use watts (displayed as kW for larger values); this convention must be checked against the connected station during live commissioning. The OpenAPI station schema does not include explicit unit metadata.

Connections are configured only by owners. Open **Deye Solar → Show solar readings** to enable or disable viewing for individual Wakil or other non-owner accounts. Sharing is off by default. A shared viewer reads the sharing owner's stations, selected dashboard station, readings and grid history without configuring a connection. Account login details, region, App ID, App Secret, password credentials and tokens are not returned to shared viewers. Viewers cannot connect, reconnect, disconnect, select the saved dashboard station or change sharing—even if an old role contains Deye edit/delete grants. Revoking sharing blocks HTTP readings and removes the solar data from subsequent live frames; the navigation and dashboard card update through the account's live permissions. Deactivating or demoting the sharing owner also blocks access.

Each owner retains an independent connection. Sharing does not combine readings from different owners. Existing legacy non-owner connections are preserved but are no longer used or monitored. The owner must explicitly share an owner connection; old Deye role grants do not enable sharing. Credentials and tokens stay encrypted server-side and are omitted from audit records. Expiring tokens are renewed automatically. Changing region/account/application requires fresh credentials. Disconnecting removes the owner's saved connection/cache; shared viewers then see that the owner has not connected Deye.

Grid availability is an **estimate from inverter grid-input voltage**, not from grid watts or cloud connection status. It requires Deye **device-monitoring permission**, a complete inventory of 1–10 inverters in the station, and fresh device measurements with supported `GridVoltage` phase keys and V/mV/kV units. Values at least 50 V on every reported grid channel indicate available; all at most 1 V indicate unavailable. Mixed phases, 1–50 V readings, missing units, unsupported models, offline devices and observations older than 15 minutes are unknown. This indicates voltage presence, not acceptable power quality. Check the readings against the inverter during commissioning.

**Observed uptime**, **observed downtime** and **unknown time** are stored per AirLink account and station from the first monitored sample. Only intervals bounded by distinct fresh samples with the same grid state are counted as uptime/downtime; duplicate samples, transitions, failed requests and gaps longer than 90 seconds between polls are not backfilled as known time. Data persists across reloads. The dashboard station continues recording while the AirLink API runs, even when the browser is closed. Other stations require an open view. Server downtime, revoked permissions and cloud gaps remain unknown; this is a cloud-based estimate, not a direct electrical outage recorder. Only active owners with saved connections are polled. Shared viewers reuse that cache and history; their own legacy connections are not polled. Disconnecting or changing the cloud account clears its history. Device inventory is cached for 30 minutes; device data follows the five-second reading cache. Device-data failure does not discard available station power readings.

The adapter uses fixed HTTPS regional endpoints and only `/v1.0/account/token`, `/v1.0/station/list`, `/v1.0/station/latest`, `/v1.0/station/device`, and `/v1.0/device/latest`. Redirects are refused. It does not use unofficial mobile app keys or expose arbitrary cloud API calls.

To control Wakil access, sign in as owner, open **Deye Solar**, click **Show solar readings**, and switch the desired account on or off. Each change saves immediately and survives restarts. This control is separate from Access Roles and cannot be delegated through a role. Configuration controls appear only for owners.
