# AirLink ISP OS 0.1.25-dev

- Tower devices sort by numeric IP address.
- Device columns appear in this order: Wireless SSID, Registration clients, ether1 speed, Uptime, Downtime, IP address, Status, Vendor, Actions.
- Add/Edit device provides a connection timeout (1–30 seconds, default 2) and update interval (15–86400 seconds, default 60). The timeout applies to ping, SNMP and API monitoring; bounded polling prevents unresponsive devices from holding the polling lock indefinitely.
- Downtime counts from the first observed failed check, appears when the availability failure threshold is reached, and clears on recovery. Stale or unknown status does not display a current downtime. Existing devices begin tracking at their next failed check; historical outage times are not invented.
- MikroTik switch is a separate saved Vendor option. It defaults to the SNMPv2c/public preset when no profile is selected and preserves custom profiles.
- Device Actions contains Edit and Delete according to account permissions. Only devices explicitly set to MikroTik switch also show Manage switch.
- Manage switch lists all Ethernet and Ethernet SFP ports reported through SNMPv2c, including disconnected and disabled ports, with Running/Not running/Unknown status, link speed and receive/transmit traffic in Mbps. The view refreshes every 15 seconds; traffic rates require two valid monitoring samples.
- Includes database migrations for connection timeout and downtime tracking, preserving existing inventory and settings. Existing update signing keys and configuration remain unchanged.

This application update includes the earlier AirLink changes. It requires a healthy installation eligible for updates; it does not clear a failed-installation recovery lock.
