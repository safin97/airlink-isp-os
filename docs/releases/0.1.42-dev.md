# AirLink ISP OS 0.1.42-dev

This update improves client-portal automatic login setup and troubleshooting.

- Owners can add and remove individual subscriber IP ranges under **My account → Client portal**, preserving existing ranges. Invalid input is rejected, failed reads cannot overwrite settings, and failed saves retain edits. Save applies the list and signs out existing customer sessions.
- When automatic login cannot verify a connection, the customer sees a reason and the source IP observed by AirLink when available. Diagnostics distinguish unlisted addresses, missing or ambiguous SAS4 sessions, stale accounting and clock mismatches without exposing customer identities or upstream secrets.
- Temporary automatic-login errors no longer prevent the manual password-login form from loading. Malformed accounting responses are rejected safely; UTC timestamps ending in Z are accepted.

Automatic login still requires the real subscriber IP to reach AirLink, an explicitly saved subscriber range and exactly one fresh SAS4 session. Adding a range does not recover an address hidden by shared NAT. This update does not change saved subscriber ranges automatically, authentication boundaries, recharge behavior or bank settings.

Install from **Software Updates** or use the signed `.airlink-update` file. This is a development application update; publishing it does not automatically update an installed server. It preserves existing data and requires no new database migration. No installer ISO or base-OS update is included.
