# AirLink ISP OS 0.1.20-dev

- Online Users has a Device login panel for each AirLink account. Device usernames and passwords are stored encrypted; leaving the password blank preserves the existing password.
- Background Ethernet speed, wireless signal and SSID readings now use authenticated device web/native API access. Online Users no longer uses SNMP, ping or inventory SNMP readings as fallbacks. Tower SNMP monitoring remains unchanged.
- Open device defaults to the saved Online Users login. Temporary credentials and named profiles remain available. Current SAS4 session validation and existing read/edit permissions still apply.
- Background collection continues without an open browser. Missing credentials, rejected logins and unavailable device services have distinct statuses; prior readings remain visible while the same session refreshes.
- SAS4 connection errors distinguish DNS resolution, refused connections, timeouts, certificate validation and interrupted connections. This improves diagnosis; it does not itself repair an installed PC’s network connectivity or an upstream certificate.

No new database migration is required. Physical device firmware interoperability remains unverified. Device services must be enabled and reachable. This is a signed application update, not a new installer ISO or base-OS upgrade.
