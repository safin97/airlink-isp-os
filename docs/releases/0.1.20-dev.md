# AirLink ISP OS 0.1.20-dev

- Move **SAS4 connection** to its own sidebar entry directly below **Settings**. Connection help and error messages point to the new location.
- Open **My account** as a normal page with separate **Account profile**, **Change password**, **Customer device access**, and **Payment setup** pages. Only the selected page is shown, and existing access requirements remain enforced.
- Make **Mimosa — SNMP v2c / public** explicit in the Towers **Add device** and **Edit** forms. Saved community profiles remain selectable, existing profiles are preserved when editing unrelated device fields, and the legacy version `2` alias is displayed as v2c in device setup.
- Include Mimosa replies in tower SNMP v2c discovery alongside MikroTik. Existing Ubiquiti v1 discovery and configured v3 discovery behavior remain unchanged. The preset community must match the radio; use a saved SNMP v2c profile for another read community.
- Add a source-checkout preview launcher with an isolated local owner login and database. Preview credentials and local edits persist across ordinary restarts. Live device, SAS4, payment, and appliance operations remain disabled in the preview; production credentials and runtime data are not included in source archives.

Existing accounts, inventory, and saved credential profiles are retained. No database migration is required. Mimosa standard uptime and interface monitoring use the existing collector; this update does not add proprietary wireless signal OIDs or establish physical-radio compatibility.

This is a development application release, not a new installer ISO, kernel, or base-OS upgrade. After the signed release is published, use **Software Updates → Check again → Update now** on an installed AirLink server configured with the existing trusted update source.
