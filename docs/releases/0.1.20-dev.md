# AirLink ISP OS 0.1.20-dev

- Online Users automatically probes Ubiquiti airOS M5/AC and MikroTik devices with SNMP v2c, then SNMP v1, using the account's saved read-only community or the optional public community.
- Device type, Ethernet speed/duplex, wireless signal, SSID and connection details are collected automatically. When SNMP is unavailable, AirLink falls back to a permitted saved device login and vendor API/web detection.
- Open device presents permitted saved profiles, their usernames, the automatic account login and temporary credentials. The new device dashboard shows the detected vendor and live wireless, Ethernet and PPPoE details.
- Device-login profile owners can choose which managers may see and use each saved password. Passwords remain encrypted and are only returned through authorized device-access operations.
- Tower device setup includes a Mimosa SNMP v2c preset. The tower device list hides the tower and SNMP-status columns requested for the compact view.
- Ubiquiti M5/AC and MikroTik connection paths remain available for opening devices. Current SAS4 session validation and existing read/edit permissions still apply.

This release adds the `device_login_profile_access` database migration. The updater applies it during installation while preserving existing accounts, inventory and encrypted credentials. Physical device firmware interoperability remains unverified; device services and SNMP must be enabled and reachable. This is a signed application update, not a new installer ISO or base-OS upgrade.
