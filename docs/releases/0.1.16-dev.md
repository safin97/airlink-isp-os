# AirLink ISP OS 0.1.16-dev

This cumulative signed application update adds device management, scoped API credentials and separate Settings pages.

- Improve tower SNMP discovery: try both v1 and v2 with saved communities, retain private credentials when a different version answers, and keep the detected vendor/version visible after adding devices. Saved v3 credentials remain required. Add Manage access for existing and newly discovered inventory devices.
- Add Manage Device for wireless SSID settings and registered clients. MikroTik RouterOS REST can change a local wireless, wifi or wifiwave2 interface SSID. Changes require Towers edit access, validate the previous SSID, and apply only after an explicit click. Changing SSID can disconnect clients. Controller-managed/inherited settings are read-only; UBNT and Mimosa SSID writes are not implemented.
- Add Settings → Device API logins. Save encrypted device usernames/passwords for towers or SAS4 managers. Tower credentials are used by monitoring and device management. SAS4-manager assignments are stored separately from SAS4 account logins; this release does not add online-user API controls or change SNMP-only customer polling.
- Add HTTPS + HTTP (auto): try HTTPS first, then HTTP when the read connection/API is unavailable. Blank ports use 443/80; a custom port applies to both. Rejected logins and uncertain settings writes are not retried over HTTP.
- Split Settings into pages for payment gateways, device API logins, SNMP profiles, network, audit log and session permissions, with sidebar links and a Back to Settings button.

Install through Software Updates → Check again → Update now. This is signed update sequence 17. Existing accounts, inventory, permissions and encrypted settings are preserved. No new database migration is required.

This development release contains the complete application package and source. No installer ISO, kernel or GPU driver package is changed. Actual device support depends on enabled SNMP/API services, firmware capabilities, credentials and network reachability.
