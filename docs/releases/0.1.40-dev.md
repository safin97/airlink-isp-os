# AirLink ISP OS 0.1.40-dev

AirLink now keeps operational screens current through quiet automatic updates. Dashboard live connections recover after a stalled stream, with background polling during disconnection. Reports, customer details, device panels, diagnostics, port status and notification history refresh in place while preserving unsaved edits. SAS4 dashboard snapshots are collected in the backend even when no browser is open; account permissions and source freshness remain enforced.

- **WhatsApp Business Cloud API:** owners can configure approved templates for successful recharge, three days before expiry, and service expiry. Each customer must be enabled explicitly. Credentials are encrypted, duplicate events are suppressed, and uncertain send results are not blindly retried. Delivery confirmation is not implemented; accepted messages mean Meta accepted the request. All notification triggers start disabled.
- **Telegram:** clearer cooldown countdowns and repeated, explicit manual tests from the connected account. Telegram's own rate limits remain enforced; this release does not provide unlimited sending.
- **Online device types:** adds Tenda, TP-Link, Ruijie / Reyee and Hikvision identification from available SNMP/public device identity. Unknown or unreachable devices remain unknown.
- **Mimosa devices:** signal replaces Wireless SSID, TX/RX Ethernet traffic replaces Registration clients, and the selected Ethernet port's speed remains visible. Values update live when reported by supported SNMP objects. Missing readings stay unavailable; measured traffic requires two valid samples.

This application update adds the WhatsApp settings, customer-consent and event tables through migration `d16ef2397542`. Existing accounts, monitoring settings and encrypted credentials are retained. WhatsApp requires an owner-provided Meta configuration and approved templates; publication does not enable messaging automatically.

Both online updating and the signed `.airlink-update` file are included. No installer ISO or base-OS update is included. This remains a development release; external message delivery and physical Mimosa hardware were not used for release tests.
