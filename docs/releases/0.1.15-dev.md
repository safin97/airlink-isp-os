# AirLink ISP OS 0.1.15-dev

This cumulative signed application update adds tower SNMP discovery and selectable device profiles, and improves tower wireless inventory.

- Add owner-only Tower actions → Discovery SNMP. Discover a management subnet using saved SNMP v1/v2/v3 profiles and public v2/v1, or select one saved profile. Identify MikroTik, Ubiquiti and Mimosa devices without requiring ping responses. Scan in bounded batches, stop between batches, and add individual devices or all results with their matching profiles.
- Add MikroTik, UBNT (M5/AC/other) and Mimosa public-community v1/v2 presets in Add/Edit Device. Keep custom-community and v3 profiles selectable. Save assigns the chosen profile; it does not change the configured vendor.
- Show ether1 speed and wireless SSID in tower device tables. Replace the CPU column with the wireless registration client count and remove the memory column.
- Open a connected-client list by clicking the registration count. Show reported MAC address, interface, SSID and signal, with permission checks, freshness indicators and bounded results. Collect registration records from supported MikroTik/Ubiquiti SNMP tables and device APIs.

Install through Software Updates → Check again → Update now. This is signed update sequence 16. Existing accounts, permissions, inventory and encrypted settings are preserved. No new database migration is required.

SNMP must be enabled with matching read credentials and network access. Community-based SNMP v2 uses v2c on the wire; v3 requires saved credentials. Device models expose different fields; Mimosa proprietary wireless telemetry is not included. This development release contains the complete application package and source. No installer ISO, kernel or GPU driver package is changed.
