## Scope and limits

This release rechecks ISO UEFI/graphical boot, offline provisioning, shipped web assets and an actual 0.1.0-to-0.1.1 application upgrade. A fresh full-disk installation was not repeated: the unchanged installer path was previously exercised with offline installation, protected-disk preservation and standalone boot in TEST-REPORT.md. The upgrade uses a small test database and unchanged schema; it does not qualify arbitrary future migrations, interrupted updates, rollback, endurance or physical hardware.

The rehearsal uses the exact signed package staged locally before publication. Public GitHub checks are recorded separately after publication. This is a development application release; full base-OS/kernel upgrades and automatic rollback remain unavailable.
