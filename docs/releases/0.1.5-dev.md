# AirLink ISP OS 0.1.5-dev

Updates the local dashboard and includes a new Debian 13 amd64 installer ISO plus a signed application update (sequence 6) for existing installations.

- ISP Card dashboard, users list and online users with service/connection status colors, compact layout and updates every 30 seconds without reloading the page.
- User information opens from the username. Edit unlocks the requested account fields; Save changes saves them to SAS4. Back leaves without a discard prompt.
- Recharge remains available during editing and preserves unsaved edits. SAS4 uses the saved service profile and expiry; opening or completing recharge does not save draft user information.
- Manager balance, Card PIN, FIB Bank, FastPay and Extend service recharge options. Extend service selects Test when available. Service profile changes respect SAS4 permissions.
- Per-account SAS4 connection, password management and encrypted merchant setup in My account. FIB Bank and FastPay require merchant credentials; sandbox payments do not activate service. Live bank payments have not been verified with merchant accounts.
- Owner management of manager, technician and viewer usernames, passwords and roles.
- NOC screen, compact tower cards with device counts, tower device navigation and management-network ping discovery.
- Full-size network map with Wi-Fi tower markers, Zakho default location and fitting to saved towers.
- Includes the existing local PC settings panel for network, hostname, date/time, services and maintenance.

## Install or update

Use `AirLink-ISP-OS-amd64.iso` for a new installation. Existing appliances can install this release through Software Updates using the signed `stable.json` and Debian package. Database migrations add SAS4 connection and payment records while retaining existing accounts and monitoring data.

This remains a development release. Physical-hardware/load qualification, automatic update rollback and full base-OS/kernel upgrades are not complete. The application package does not upgrade the kernel.
