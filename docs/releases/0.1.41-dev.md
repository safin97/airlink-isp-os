# AirLink ISP OS 0.1.41-dev

Customer self-service is now available at `/client`, with a responsive dark-blue dashboard, Home/Usage/Packages/Support/Profile navigation, live SAS4 account details, subscription expiry, PIN recharge and FIB Bank checkout. Customer sessions remain separate from staff access. Password login uses the subscriber’s SAS4 credentials; automatic login is limited to explicitly configured subscriber networks and a fresh, unique RADIUS session match.

- **Package payments:** every AirLink plan card has Pay. Checkout selects that package, checks unused SAS4 PIN stock and displays its actual IQD value. The customer’s profile changes only after verified production FIB payment, followed by a single PIN recharge. Unavailable stock or profile-change permissions block checkout. Uncertain operations require provider review and are not automatically replayed. Sandbox payments do not change service.
- **SAS4 Card System:** manage Radius cards within ISP Card, with profile-aware prices, encrypted reservations, a five-minute FIB payment window, and explicit handling of expired, declined and unconfirmed payments. Blank aggregate used-card counts trigger individual-card checks rather than reporting sold out.
- **Customer connection tools:** wireless signal when available, internet checks and an animated speedometer with measured download/upload throughput and HTTP ping/jitter. No synthetic customer information or usage totals are displayed. Speed tests contact Cloudflare and use up to 26 MB; Speedtest.net remains available as an external link.
- **Operations:** preserves current inventory while refreshing, improves SAS4 online-client reporting and GPU diagnostics, and adds owner-only L2TP/IPsec VPN controls for the installed Linux appliance.

Five schema migrations add saved-card inventory, payment reservations and separate client portal settings/sessions, ending at `b08de7149f25`. Existing customers, staff accounts and encrypted credentials are retained. The customer portal requires owner configuration and saved SAS4 access. FIB requires valid merchant configuration and matching unused SAS4 cards; package changes also require SAS4 profile-change permissions.

This is a signed development application update with online and `.airlink-update` offline assets. It does not replace the installer ISO or base OS. Existing installations need `network-manager-l2tp` and `strongswan` installed separately to use VPN; see `docs/VPN.md`. Bank and service-change tests use controlled fixtures; no real customer payment is made for release validation. Mobile layouts are tested, but physical Android/iPhone, live bank fulfillment and live VPN tunnels are not certified by this release.
