# AirLink ISP OS 0.1.13-dev

This signed application update improves online-user device telemetry and adds SAS4 reports and parent manager links.

- Identify MikroTik, Ubiquiti and Mimosa devices from SNMP, supported authenticated API responses and public device web branding. Unknown devices remain unidentified.
- Try configured SNMP communities with v1 first, then v2, followed by saved v3 credentials within bounded probe timeouts. The interface displays SNMP v2; community-based connections use the v2c protocol. SNMP v3 requires saved credentials and now offers SHA1, SHA256 or MD5 authentication and AES128 or DES privacy.
- Show device type in Online Users. Preserve partial Ethernet and signal readings and distinguish reachable devices with unavailable SNMP telemetry from unreachable devices. Readings still require a responding device protocol; vendor detection alone does not supply signal or link speed.
- Add ISP Card reports for Activations, Activation statistics and Money Transfers. Default to monthly activation statistics, filter by one month, select a SAS4 manager by typing at least two letters, and load changed filters automatically.
- Add an optional parent manager when creating or editing a manager account. Parent links do not grant permissions or inherit place access. Self-links and cycles are rejected.
- Avoid rebuilding unrelated dashboard pages for live system-summary updates, preserving search and form state.

Install through Software Updates → Check again → Update now. The signed update uses sequence 14 and adds the manager hierarchy database table. Existing accounts, permissions, inventory, encrypted credentials and HTTPS configuration are preserved.

This is a development application update. No installer ISO, kernel or GPU driver package is included. Some sampled customer devices still do not answer SNMP despite responding to ping; this release does not claim to resolve their device or network configuration. Mimosa identity and standard Ethernet data are supported; proprietary Mimosa wireless signal collection is not included.
