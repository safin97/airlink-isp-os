# AirLink ISP OS 0.1.8-dev

This signed application update adds customer device telemetry, SNMP compatibility and faster update discovery.

- SNMP v2c and legacy v1 profiles alongside existing v3 profiles, with encrypted credentials and MikroTik/airMAX M5/AC radio adapters.
- Separate SNMP connection status in Towers → Devices.
- ISP Card → Online users shows reported Ethernet link speed, signal and authenticated connection source. Background checks use the customer's current session IP without requiring inventory setup.
- My account → Customer device access stores device API credentials and an optional SNMP community. Owners can reuse saved SNMP profiles; managers use their own device credentials.
- Automatic SNMP version/vendor detection, MikroTik RouterOS REST and legacy airOS status API fallback. Credentials and reachable/enabled device services are required. Native RouterOS TCP API ports 8728/8729 are not included. Unsupported or failed readings remain unavailable.
- Existing HTTPS dashboard certificates now include current local IP addresses at startup/update. Custom operator certificates are preserved. Local device certificates still require browser trust; this update does not create a public certificate for a private IP.
- Dashboard files revalidate over HTTPS to prevent stale versions. Software Updates checks the signed GitHub release every 30 seconds while open, with no-cache requests. Installation remains owner-controlled.

The update migrates the database to store encrypted customer probe settings. It preserves existing accounts, inventory and credentials. No installer ISO, kernel or GPU driver update is included. Use Software Updates → Check again → Update now. On older releases, Check again discovers this release immediately; the shorter automatic check interval applies after installation.
