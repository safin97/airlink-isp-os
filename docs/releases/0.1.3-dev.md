# AirLink ISP OS 0.1.3-dev

Adds **Restart system** beside **Schedule update** in Software Updates.

- Owner-only restart with a confirmation dialog explaining the brief interruption.
- Restart works even when no new release is available. The dashboard waits for a changed Linux boot identity before reporting success.
- Queued/active installations, failed-installation recovery and concurrent update operations block restart. A pending restart also blocks new installation work and duplicate requests.
- Restart requests are audited and run through a fixed privileged systemd action with a short delay so the response can reach the dashboard.
- The Mac preview cannot restart the computer; use the dashboard hosted by the AirLink appliance.

## Application update only

Install the signed sequence-4 package through Software Updates. This release does not rebuild or replace the local ISO or deploy to an existing PC. For a new installation, the [0.1.2-dev installer ISO](https://github.com/safin97/airlink-isp-os/releases/download/v0.1.2-dev/AirLink-ISP-OS-amd64.iso) remains available, followed by this signed application update.

The release is published as GitHub Latest for the existing signed feed. It remains a development build; hardware/load qualification, automatic rollback and full base-OS/kernel upgrades are not complete.
