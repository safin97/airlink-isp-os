# AirLink ISP OS 0.1.30-dev

The owner can configure each account's Telegram notifications directly from **Managers → Add/Edit account → Telegram notifications**. Choose **English, Kurdish Badini, or Arabic** before saving or sending a test. The selection is saved per account and applies to alert statuses and connection test messages, independently of the dashboard language.

**Next: Edit messages** provides separate device-down/timeout and recovery templates, sample previews, and **Restore defaults**. Default messages now include the tower name. Supported placeholders are {status}, {device_name}, {ip_address}, {tower_name}, and {time} (UTC). Arabic and Kurdish message editors and previews use right-to-left text. Switching language translates unmodified defaults and preserves custom wording; Restore defaults loads translated templates for the selected language.

Messages are plain text, limited to 1,000 template characters, and apply to newly queued alerts. Existing queued messages keep their original text. Templates and language can be configured before connecting a bot.

This cumulative signed development application update includes 0.1.29-dev and adds per-account message templates and a language setting. Existing connections, accounts, inventory, credentials, and saved custom messages are preserved; existing accounts default to English. Telegram remains scoped to each account's authorized devices. Live Telegram delivery was not exercised during release validation. This is an application update, not a kernel or base-OS upgrade. Install through **Software Updates → Check again → Update now**.
