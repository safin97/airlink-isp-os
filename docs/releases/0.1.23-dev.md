# AirLink ISP OS 0.1.23-dev — cumulative update

One complete signed application package containing the application changes delivered from 0.1.5 through 0.1.22. Existing healthy 0.1.5 installations can upgrade directly; intermediate releases are not required. Database migrations run in order from the installed schema to the current version.

Included capabilities:

- ISP Card users, online users, recharge workflows, SAS4 account connections and reports, plus encrypted payment-provider configuration.
- English, Kurdish Badini and Arabic, day/night styles, live dashboard updates, NOC fullscreen, local clock and PC performance readings.
- Places, towers, manager assignments, reusable access roles, section Read/Edit/Delete permissions and manager parent links.
- Tower ping/SNMP discovery, SNMP v1/v2c/v3 profiles, MikroTik/Ubiquiti/Mimosa identification and Mimosa v2c presets, wireless and Ethernet readings, and registered-client lists where supported.
- Online-user device detection, signal, SSID, Ethernet speed/duplex and connection details, with supported SNMP and authenticated device connection fallbacks.
- Open device for supported MikroTik RouterOS and Ubiquiti airOS M5/AC devices, saved or temporary logins, manager-scoped saved profile access, device overview panels and supported SSID controls.
- Separate Settings pages, Device Login Profiles, HTTPS/cache improvements and the Diagnostics sidebar with service/update problems and recent error logs.
- The 0.1.22 health-check fix: startup retries cover the API, required services and worker heartbeats, and failures identify the unavailable component.

Existing accounts, inventory and encrypted credentials are retained. Device readings and management require supported firmware, enabled services, valid credentials and network reachability; the update does not configure remote routers automatically. Payment integrations still require configured provider accounts.

Install through Software Updates → Check again → Update now. Signed update sequence: 24. This is an application update, not an installer ISO, kernel or GPU-driver update.

An appliance already showing a failed-installation recovery lock still needs local recovery review. This cumulative package does not bypass that lock, erase data or provide automatic rollback.
