# AirLink ISP OS 0.1.36-dev

This update adds downloadable encrypted backups, recovery from a PC file, weekly MEGA backups and recovery, and owner-controlled Deye Solar sharing.

- **Settings → Backups → Download a backup:** save an encrypted AirLink backup to your computer without a cloud account or domain.
- **Restore from PC file:** browse a saved `.tar.airlink` backup, upload it in small chunks, enter its encryption password, and verify it before typing `RESTORE` to confirm. Recovery saves a safety copy before replacing the database. Sign in afterward using an account from the backup.
- **MEGA cloud backup:** save and test your MEGA account, then back up on demand or every week. Choose the day, time and timezone. Select **Restore from MEGA** to verify and recover a saved cloud backup. Keep the backup encryption password outside AirLink. Accounts requiring a fresh one-time sign-in code are not supported for unattended backups.
- Google Drive backup settings, OAuth routes and its scheduler have been removed. Existing cloud files are not deleted. Previously downloaded AirLink archives can be recovered through the compatible file-recovery workflow.
- Only owners configure Deye Solar. Owners use **Deye Solar → Show solar readings** to give Wakil or other active accounts read-only access to their solar readings. Shared accounts never receive Deye credentials or configuration rights. Sharing is off until an owner enables it; legacy delegated Deye edit permissions no longer grant access.

Install through **Software Updates → Check again → Update now**. This release adds the `deye_shares` database table and bundles the MEGA transfer helper in the application package. Existing application data and saved integration credentials are preserved.

Recovery replaces current database records and discards changes made after the chosen backup. Local SQLite and appliance PostgreSQL backups are not interchangeable. Online recovery supports files up to 20 GiB, subject to available space. Appliance web recovery keeps current network settings and requires the backup's credential-encryption key to match the installation; use console recovery for a different key. Local Mac recovery applies when the live server is stopped and started again.

This is a signed development application update, without a new installer ISO or base-OS/driver upgrade. Publishing does not install the update automatically or clear a previous failed-update lock. Keep the server running and online for scheduled MEGA backups; transfer quotas and storage limits still apply.
