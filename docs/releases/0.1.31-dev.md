# AirLink ISP OS 0.1.31-dev

Deye Solar now connects to your Deye Cloud account using its region and developer App ID/App Secret. The dashboard shows a compact live diagram with solar panels, battery, grid, load and inverter, including battery charge/discharge and grid import/export power. Choose its station in Deye Solar. The account’s dashboard station is monitored in the background, targeting cloud checks every five seconds; updates stream into the existing view without periodic reloads. Reconnects and quiet polling recover dropped live connections. Actual reading freshness depends on inverter uploads to Deye Cloud.

Deye Solar Read, Edit and Delete permissions are available in Access Roles. Connections and encrypted credentials remain private to each AirLink account. The detailed solar section includes observed grid uptime/downtime estimates from supported inverter voltage measurements; missing, stale and ambiguous data remain unknown. These are cloud estimates, not direct electrical outage measurements.

Owners can use **Diagnostics → PC & driver updates** to check installed Linux system packages, kernel/drivers, firmware and CPU microcode online, review exact versions, then confirm installation. Jobs use the appliance’s existing signed APT repositories, preserve configuration, and share the maintenance lock with AirLink application updates and restarts. This feature requires an installed Linux appliance; the Mac preview cannot update its host. Installing this release does not itself install PC/driver updates or reboot the appliance.

This cumulative signed development application update includes the Telegram message editing, tower-name placeholders and per-account English/Kurdish Badini/Arabic notification language options from 0.1.30-dev. Existing accounts, settings, inventory and credentials are preserved. Three additive Deye database migrations are included.

Install through **Software Updates → Check again → Update now**. This release is an application package; no new installer ISO is included. Physical GPU/CPU driver upgrades and live inverter hardware were not part of the disposable-VM installation rehearsal. Deye Cloud connectivity was separately checked against the saved local account.
