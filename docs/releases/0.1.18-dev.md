# AirLink ISP OS 0.1.18-dev

- Owners can show or hide SNMP profiles for individual manager accounts or all non-owner accounts. Profile visibility changes take effect in live sessions. Credential values remain hidden; existing edit permissions are separate.
- Tower SNMP discovery shows Ubiquiti devices for v1 and MikroTik devices for v2. Auto discovery continues trying profiles until the vendor/version matches; v3 retains all detected vendors.
- After discovery, Apply SNMP assigns the discovered profile to an existing device in the selected tower without creating duplicates or replacing unrelated settings. Stale device IP, tower or profile changes are rejected.
- Device Login Profiles is available in the left sidebar for accounts with ISP Card access. Save named, encrypted device credentials, then choose a profile in Online Users → Open device → Connect. Each account’s profiles are private; the automatic SAS4 manager login remains available.

This update adds database tables for profile visibility and reusable device logins. Existing accounts, inventory and credentials are preserved. Profile creation/editing/deletion follows ISP Card permissions; tower SNMP assignment remains owner-only.

This is a signed development application update, not a new installer ISO, kernel or GPU driver update. MikroTik device panels require reachable RouterOS REST; Ubiquiti PPPoE and Mimosa API access remain unavailable. Background customer telemetry remains SNMP-only.
