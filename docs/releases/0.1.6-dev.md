# AirLink ISP OS 0.1.6-dev — GPU-capable ISO

- Bundles NVIDIA's open kernel driver and graphics libraries from its signed Debian 13 repository, pinned to the 610 branch. Supported RTX cards are detected through normal Linux PCI/udev driver binding, including during offline installation.
- Adds read-only GPU detection to the owner-only system status API and PC settings → Overview. NVIDIA cards report model, driver version, VRAM use, utilization and temperature when available.
- Keeps Mesa support for other graphics adapters and does not force a primary GPU on hybrid systems.
- Retains all 0.1.5-dev dashboard, ISP Card and recharge behavior.

The GPU driver is part of the ISO/base system. Application-only updates do not install it on an older OS. The monitoring worker remains a CPU/network/database workload; this change does not claim a higher device capacity or add CUDA-based monitoring.

Physical RTX hardware and Secure Boot are not qualified by the QEMU checks. A VM requires actual GPU assignment/passthrough to use a host RTX card. See [GPU support](../GPU.md) for details.
