# AirLink ISP OS 0.1.6-dev

GitHub application update for existing AirLink installations. No new installer ISO is included.

- English, Kurdish Badini and Arabic language selection, right-to-left layouts and a saved browser language preference.
- Day and night styles with a saved browser preference. Language and style changes preserve form input and the current session.
- My account moved into the sidebar below Settings. The owner can configure FIB Bank and FastPay directly in Settings → Payment setup.
- User lists show 18-pixel status squares before the username, with status details on hover. Usernames are black and semibold as requested.
- Recharge opens with selectable squares for Manager balance, FIB Bank, FastPay, Extend service and Card PIN. Existing payment verification, SAS4 permissions and unsaved-edit behavior are retained.
- Expand NOC hides the navigation and header and requests browser fullscreen. F12 toggles the NOC view where the browser permits the shortcut; Exit fullscreen restores navigation. Browsers that deny fullscreen retain the NOC-only layout.
- NOC includes the signed-in owner's or manager's SAS4 online-user count, updated every 30 seconds while the NOC is open. Unavailable data is shown as unavailable, rather than zero.
- PC settings → Overview and the owner-only system API can report detected GPUs, driver status and NVIDIA telemetry when an appropriate driver is already installed.

## Update

On the installed AirLink PC, open Software Updates, check for updates, then choose Update now. The signed sequence-7 manifest and Debian application package are verified by the existing updater. Services restart during installation; a full PC reboot is not required.

This release does not change the kernel, install NVIDIA drivers or rebuild the ISO. The existing 0.1.5-dev ISO remains the installer for new PCs; install it and then apply this update. NVIDIA driver support in the ISO build recipe is separate from this application package.

This remains a development release. Physical-hardware/load qualification and automatic update rollback remain incomplete. FIB Bank and FastPay require merchant credentials and provider verification; live merchant payments have not been qualified here.
