# AirLink ISP OS 0.1.34-dev

Device availability now displays only **Online** or **Offline**. The Unknown status, dashboard count and health-bar segment have been removed from the dashboard and Network Operations Center.

- Online requires a recent online reading. New devices, disabled monitoring, stale readings and pending initial checks display Offline.
- Tower summaries and device totals use the same availability rules.
- Polling failure thresholds, confirmed outage durations, outage history and alert rules remain unchanged. An Offline display caused by missing telemetry does not create a confirmed outage duration.

Install through **Software Updates → Check again → Update now**. This signed application update includes no database migrations and preserves existing accounts, inventory and settings.

This is a development application update, without a new installer ISO or base-OS/driver upgrade.
