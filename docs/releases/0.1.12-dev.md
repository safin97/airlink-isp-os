# AirLink ISP OS 0.1.12-dev

This signed application update adds live dashboard data, automatic device identification and direct user-list recharge access.

- Replace the dashboard’s 30-second refresh with an authenticated live connection. Changed resources arrive about every two seconds, with automatic reconnection and token renewal. Permissions are rechecked continuously; searches and open forms remain intact.
- Check visible SAS4 data and NOC online-user counts every five seconds. Device telemetry still follows configured collection intervals.
- Add a local-time clock to the top bar, updating every second.
- Detect device vendors from SNMP identity and authenticated device API responses. Auto detect is the default for Generic devices; supported identities include MikroTik, Ubiquiti M5/AC and Mimosa. Manual selections remain available, and unknown devices remain Generic.
- Add Google DNS latency to 8.8.8.8 and Gaming ms to 1.1.1.1 in PC Performance. Gaming ms is an internet connection reference, not actual PUBG or Call of Duty server ping. Failed ICMP probes show No reply, not zero.
- Keep System TX/RX and individual Ethernet cards hidden from the dashboard.
- Open Recharge Card directly from each row in All Users, immediately before Profile. Existing recharge confirmation, permissions and payment controls apply.

Install through Software Updates → Check again → Update now. This is a development application update; no installer ISO, kernel or GPU driver package is included. Accounts, permissions, inventory, credentials and HTTPS configuration are preserved.
