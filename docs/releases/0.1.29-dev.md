# AirLink ISP OS 0.1.29-dev

- GPU cards in Dashboard → PC performance display model, utilization, VRAM, temperature and driver status using existing NVIDIA support. This application update does not install kernel drivers or enable GPU acceleration for monitoring.
- NOC sound alerts announce device down/timeout events. Sound attempts to enable when opening NOC; browsers may require an Enable sound click. Mute remains available.
- My account → Telegram notifications gives owners and managers separate encrypted bot credentials and destinations. Down and recovery notifications run in the background, scoped to authorized devices, with permissions rechecked before sending and bounded retries.

This cumulative development application update includes 0.1.28-dev and adds Telegram database tables. Existing accounts, inventory and credentials are retained. No Telegram messages are sent until an account configures and enables its connection. Live Telegram delivery and physical NVIDIA hardware have not been tested. Install through Software Updates. This is not a kernel or base-OS upgrade.
