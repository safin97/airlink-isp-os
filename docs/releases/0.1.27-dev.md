# AirLink ISP OS 0.1.27-dev

This cumulative application update includes all published changes through 0.1.26-dev and the following improvements.

- A professional Towers API login screen with the AirLink logo, saved-profile connection details, clear loading/error states and manual retry. Owners can add saved logins directly; manager access remains limited to shared profiles and authorized towers.
- Native MikroTik API and API-SSL profiles, including default/custom ports and TLS verification settings.
- A responsive device workspace with Overview, Ethernet, Wireless and Settings tabs; all reported Ethernet/SFP ports, running/link status, speed, RX/TX traffic, wireless interfaces and registered clients; port search and filters; light/dark layouts and automatic refresh.
- Reviewed configuration changes for device identity, Ethernet, wireless, IPv4 addresses, DNS and routes. Saves recheck permissions and current values, reject dynamic/controller-managed settings and never automatically retry uncertain writes.
- Simplified SNMP version choices: SNMP v1, SNMP v2, SNMP v3 and SNMP v2c, with separate saved credentials and public community presets.
- Owner-only Google Drive backup settings, encrypted manual backups and weekly automatic scheduling. Restore, update and backup operations share the maintenance lock.
- A live local development mode that uses saved integrations and background monitoring without resetting local inventory.

Google Drive backups require owner-configured Google OAuth credentials, an HTTPS callback domain, a linked Drive account and a backup encryption password. They are not connected or scheduled merely by installing the update. Supported local application settings and saved credentials are preserved.

The MikroTik device must expose the selected service and accept its saved account. Editing also requires RouterOS write permission. This panel is not a full WebFig replacement. Automated and disposable-system validation does not replace live testing on each hardware model. Live router configuration writes and uploads to a connected Google Drive account were not exercised during release validation.

Install through Software Updates after reviewing the release. This is a signed development application update, not a base-OS or kernel upgrade. Existing installations in a failed-update state still require local recovery review before another installation.
