# AirLink ISP OS 0.1.10-dev

This signed application update adds places, manager access controls and tower API monitoring.

- Organize Towers by place, then open a place to view its towers and devices.
- Assign places in Add/Edit Manager. All current and future towers in selected places are included. Existing individual tower assignments remain until a new place selection replaces them.
- Configure each manager’s visible sections and separate read-only/edit permissions. Settings and Software Updates are opt-in. Permissions are checked on every request; the owner retains full access.
- Add encrypted device API settings per tower for MikroTik RouterOS REST and Ubiquiti airOS M5/AC. Tower devices can report Ethernet speed, wireless readings, CPU, memory and uptime when supported and reachable.
- Show PC CPU, memory, storage and disk activity on the dashboard; remove its bandwidth/history panel. Historical monitoring remains in Monitoring.
- Preserve HTTPS, update signing, account credentials, existing inventory and SNMP monitoring. New database tables are migrated automatically during installation.

Section grants do not bypass inventory scope or owner-only account administration. Read-only managers cannot edit devices, recharge cards, change settings, install updates or restart the PC without the relevant edit grant. Existing grants retain their prior behavior until the owner configures edit permissions.

Install through Software Updates → Check again → Update now. This is a development application update; no installer ISO, kernel or GPU driver package is included. Hardware telemetry depends on the device firmware, enabled services and valid credentials.
