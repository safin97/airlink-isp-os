# AirLink ISP OS 0.1.7-dev

Fixes Linux service permissions for Towers → Discover with ping.

- Grants the unprivileged AirLink API service the CAP_NET_RAW capability required for ICMP discovery.
- Retains NoNewPrivileges, filesystem isolation and address-family restrictions. The capability bounding set is limited to CAP_NET_RAW, matching the existing monitoring service.
- Keeps existing tower access controls and the /24–/32 discovery limit. Hosts must still be reachable and allow ICMP replies.

## Update

On your installed AirLink PC, open Software Updates, check again, then choose Update now. The signed sequence-8 application update reloads systemd configuration and restarts the API so the permission fix takes effect. No full PC reboot is required.

Application-only development release. No ISO, kernel or NVIDIA driver update is included. All 0.1.6-dev dashboard changes are retained.
