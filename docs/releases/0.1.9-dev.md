# AirLink ISP OS 0.1.9-dev

This signed application update simplifies Online users and speeds up customer SNMP checks.

- Hide Name and Profile in ISP Card → Online users. The regular Users list retains both columns.
- Add the explicit “Check SNMP with public community” option under My account → Customer device access, enabled by default. It checks public using v2c then legacy v1 before other saved credentials; it can be disabled.
- Customer SNMP checks now read Ethernet link status/speed and radio signal without the CPU, storage and traffic-counter walks used by full inventory monitoring.
- Identify detected MikroTik SNMP connections in the Connection column.
- Preserve custom SNMP credentials, API credentials, account permissions, HTTPS and the 30-second release checks from 0.1.8.

MikroTik must have SNMP enabled, public read access and UDP 161 access from AirLink. Setting trap-community=public alone does not enable polling. This release does not configure remote routers or add an SNMP trap receiver. Unreachable or unsupported readings remain unavailable.

Install through Software Updates → Check again → Update now. This is an application update; no installer ISO, kernel or GPU driver package is included.
