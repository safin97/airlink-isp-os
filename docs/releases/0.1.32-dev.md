# AirLink ISP OS 0.1.32-dev

This application update improves Deye Solar power flow, adds automatic local-display graphics selection, and adds driver health to Diagnostics.

- Deye Solar shows continuously animated solar, battery, grid and load flows using the latest confirmed cloud measurements. Battery charging/discharging and grid import/export prefer complete, fresh inverter readings; ambiguous station values no longer imply export. Stale data, unknown grid state and reduced-motion settings stop the relevant animation. On-grid/off-grid badges identify voltage-based estimates.
- The installed PC settings panel prefers NVIDIA OpenGL compositing, then other working graphics hardware, with CPU-rendering fallback. A real Qt frame probe runs before enabling acceleration. Monitoring stays on the CPU; no fixed GPU utilization, power-limit or clock changes are applied. The selected renderer appears in PC settings → Overview.
- Diagnostics → Drivers & device health lists detected Linux devices, bound drivers, available versions, CPU scaling details, GPU telemetry and loaded kernel components. Search and status filters distinguish Loaded, Needs attention and Unknown. Loaded is not a performance benchmark or a guarantee that a driver is up to date. Refresh diagnostics rescans the running PC.

Install through Software Updates → Check again → Update now. Existing accounts, device settings and connections are preserved. This signed application update uses the existing publisher key and does not ship an installer ISO, install missing NVIDIA kernel drivers, update BIOS/UEFI or automatically reboot the PC. Driver acceleration requires compatible hardware and installed drivers; physical NVIDIA testing is still required on the target PC. Deye data freshness depends on inverter uploads and Deye Cloud; grid status is an estimate, not a confirmed relay mode or inverter control.
