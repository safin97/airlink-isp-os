# AirLink ISP OS 0.1.0-dev

First public development release of the AirLink monitoring appliance.

Includes a Debian-based amd64 UEFI installer ISO, Flutter dashboard, FastAPI/PostgreSQL backend, independent SNMPv3/ICMP workers, role-based access, network rollback, and signed application updates through GitHub Releases.

## Downloads

- `AirLink-ISP-OS-amd64.iso`: GitHub-configured development installer (Secure Boot disabled).
- `airlink-isp-os_0.1.0-dev_amd64.deb` and `stable.json`: signed application update for an existing compatible AirLink installation. Install through the Update Center after trusting the publisher key.
- `AirLink-GitHub-Configuration.zip`: initial publisher configuration for the earlier unconfigured ISO.
- `SHA256SUMS`: integrity checks for release assets. The updater verifies the Ed25519 manifest signature and package hash independently.

This is a development build, not a production-certified appliance. Generic SNMP metrics are implemented; vendor-specific wireless/client adapters, full base-OS/kernel upgrades, and automatic rollback remain incomplete. Read PROGRESS.md and the test reports before deployment.

The updater's public `latest/download/stable.json` endpoint requires a regular published GitHub Release. This release is therefore discoverable through that endpoint while explicitly retaining its development designation. Updating is owner-triggered, not automatic on publication.
