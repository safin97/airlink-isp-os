# AirLink ISP OS 0.1.2-dev

Development release applying the owner's supplied AirLink logos throughout the graphical interface.

- Original stacked artwork on sign-in/setup screens, compact mobile headers and application icons.
- Original horizontal artwork in dashboard navigation, startup/loading screens, installer headers and the repository header.
- Browser favicon uses the original logo symbol. Light logo panels preserve the supplied navy and blue colors.
- Branded UEFI boot menus for the ISO and installed systems. Signed application upgrades install the theme and regenerate the installed GRUB menu without replacing other site GRUB settings.
- The Linux text console retains the AirLink name; text terminals do not display PNG images.

The GitHub update source, owner-confirmed in-page updates and verification safeguards are retained.

## Downloads

Use `AirLink-ISP-OS-amd64.iso` for a new x86_64 UEFI installation with Secure Boot disabled. Existing configured appliances receive the signed sequence-3 package through Software Updates.

This is a development build. Full base-OS/kernel updates, automatic rollback, vendor wireless/client adapters and physical hardware qualification remain incomplete. See PROGRESS.md and RELEASE-VERIFICATION.md for validation scope.

This release is listed as GitHub Latest so the configured signed-update feed can find it. Installation remains owner-confirmed.
