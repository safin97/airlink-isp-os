## Validation

- 92 Python tests passed; one Linux-only package test was skipped on macOS. Coverage includes owner-only API access, strict confirmation, audit records, update/restart locking, queued and failed installations, duplicate requests, failed command cleanup and queued-installer lock handoff.
- 13 Flutter tests passed and the analyzer was clean. Restart cancellation performs no action; confirmation submits the fixed request; the UI requires a changed boot identity before success and disables restart for preview, queued/active/failed installations or an already pending restart. Restart is available even without an available update.
- The web bundle was built to a separate release directory. Hash checks confirm the existing local ISO and preview web bundle were not changed.
- The exact signed package passed a real 0.1.2-to-0.1.3 upgrade in a disposable QEMU overlay. Signature, package identity, backup checksums, migration/health checks, service activation, owner access, test inventory, encrypted credentials and replay protection passed.
- The upgraded disk booted normally through UEFI. The actual authenticated owner API returned HTTP 202 for a confirmed restart and rejected an unconfirmed or duplicate request.
- The scheduled privileged systemd action rebooted that VM. The API returned with a different Linux boot identity and no pending-restart flag. Owner login, inventory, required services and the persistent restart audit record were verified after reboot.

## Publication scope

This is a GitHub application release only. No ISO was rebuilt or replaced, and the local preview was not deployed. Existing appliances obtain the signed package through Software Updates; new installs can use the existing 0.1.2-dev ISO and then update. Tests restarted only disposable QEMU resources, never the host Mac or a user PC.

This remains a development appliance; physical hardware/load qualification, interrupted-upgrade recovery, automatic rollback and full base-OS/kernel upgrades remain incomplete. Evidence is in `test-results/release-013/` and `/tmp/airlink-013-*-tests.log`. Public download verification is recorded after publication.
