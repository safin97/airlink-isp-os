# AirLink ISP OS 0.1.38-dev

Software Updates now includes **Update from file**. Download the `.airlink-update`
asset from a release on any computer, browse for it in AirLink, upload and verify,
then select **Install verified update**. The server does not need internet access,
and an online check error does not disable local updating.

The uploaded file contains the signed release manifest and Debian package. AirLink
uses its existing trusted publisher key to verify the signature, expiration,
release sequence, package digest, size, architecture and version. Uploading does
not install anything. Installation requires confirmation and uses the normal
database backup, migration, service restart and health checks.

Local updates follow the existing Software Updates edit permissions. Read-only
users cannot upload or install. Uploads are bound to the signed-in user, can be
cancelled, and expire after one hour of inactivity. Invalid files and older
releases are rejected. Failed installations still require recovery review.

Install this release once to get the new browse-file option. Earlier dashboards
do not have the button. Saved settings, MEGA backup configuration and monitoring
data are preserved. This application update does not change the installer ISO.
