# AirLink ISP OS 0.1.14-dev

This cumulative signed application update includes all current changes, with SNMP-only customer telemetry that runs without an open dashboard.

- Show seven items per page in ISP Card Users List and Online Users.
- Start background online-user collection with the backend. Cycle through all online pages using each eligible account's saved SAS4 connection, with bounded device concurrency and retries. The PC and AirLink backend must remain running; a browser session is not required.
- Keep last reported Ethernet speed, signal and SSID visible during checks and temporary failures. Replace them when new readings arrive; tooltips identify retained readings, and empty values show Checking while a check runs. Cached readings are rebuilt after a backend restart.
- Use SNMP only for online-user device readings and identification. Remove customer device API login and transport controls from My account. The SAS4 connection still supplies users and reports; tower device API monitoring remains available separately.
- Prefer the named ether1 Ethernet port when it is active, otherwise show actual active Ethernet port names. Add the SSID column. Use MikroTik station-mode signal and SSID tables, retaining the registration table as a signal fallback; also read the Ubiquiti airMAX SSID table. Ambiguous radio data is not assigned to an arbitrary customer link.
- Improve SNMP v2 table polling with bounded GETBULK requests and a GETNEXT fallback. Accept version 2 as an alias for the community-based v2c protocol. Incomplete v1 readings also try v2; configured v3 credentials remain supported.

Install through Software Updates → Check again → Update now. This is signed update sequence 15. Existing accounts, permissions, inventory and encrypted settings are preserved. No new database migration is required.

This release contains the complete application package and source, not a new installer ISO, kernel or GPU driver package. Live checks on three sampled customer devices still failed SNMP v2; these software changes do not enable SNMP or change device/network access rules. Mimosa proprietary wireless signal collection is not included.
