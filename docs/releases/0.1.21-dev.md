# AirLink ISP OS 0.1.21-dev

- Adds a **Diagnostics** section to the left navigation for owners and managers with Settings access.
- Diagnostics combines failed services, CPU/memory/storage warnings, the persisted software-update state, recovery-required details and recent error-level AirLink service journals.
- Password-, token-, secret-, authorization- and SNMP-community-like journal values are redacted before diagnostic lines reach the browser.
- A failed or interrupted update remains recovery-locked. Diagnostics explains the recorded failure but does not silently clear the marker, retry installation or roll back database/application state.
- Includes all v0.1.20 device-dashboard, manager-scoped device-login profile access, Mimosa SNMP v2c and automatic Ubiquiti/MikroTik SNMP v2c/v1 detection changes.

This package includes the idempotent `device_login_profile_access` migration introduced in v0.1.20. Existing accounts, inventory and encrypted credentials are preserved. Appliances already marked with a failed installation require local recovery review before any newer package can be installed. This is a signed development application update, not a base-OS or kernel update.
