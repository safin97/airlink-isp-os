# AirLink ISP OS 0.1.47-dev

Devices can automatically display an available Ethernet link speed, or use a port selected in the Ethernet details dialog. Registration client counts show online, offline and unknown clients, and the dashboard makes GPU activity clearer.

- **Ethernet speed:** fixes the Mimosa C5c display when link speed is reported separately from traffic counters. Automatic selection prefers an available ether1, then the previous available port, then another reported port. The Ethernet dialog lets authorized editors save a specific port for each device. Last reported speeds and their observation times remain visible during outages; a selected port never borrows another port's reading.
- **Registration clients:** device rows show online/offline counts and unknown counts when status cannot be confirmed. The client dialog keeps stable row order by default and adds Online first and Offline first sorting. Counts come from observed client history; unsupported client lists do not produce fabricated offline counts.
- **GPU dashboard:** GPU cards follow CPU, showing measured utilization with a progress bar, Working · Active or Working · Idle status, model, VRAM, temperature and driver details. Missing drivers and unavailable readings remain explicit. Physical GPU and Mimosa C5c readings still depend on the installed driver and device telemetry.

Database migration `e97ab6038214` adds the optional per-device Ethernet display port. Existing devices default to Automatic; other saved device settings are preserved.

This signed development application update is available through Software Updates and the `.airlink-update` offline bundle. It does not replace the installer ISO, install GPU drivers or automatically install on existing servers. A PC reporting local recovery review still requires diagnosis and repair before a blocked update can proceed.
