# AirLink ISP OS 0.1.4-dev

Adds an owner-authenticated **PC settings** screen on the installed appliance's display, using the supplied AirLink branding.

- First-owner setup and owner login; automatic lock after five minutes of inactivity.
- Ethernet DHCP/static IPv4, subnet prefix or mask, gateway and DNS, with current settings and a 120-second keep/revert countdown backed by NetworkManager rollback.
- Hostname, searchable timezone selector and manual date/time. Automatic time synchronization is offered when a supported NTP service is installed; the current development ISO has no NTP service.
- Service status, signed GitHub application updates, update scheduling, local backups/database restore, system logs, service restart, system restart and shutdown.
- Owner checks on every local administrative operation and guards against conflicting maintenance/update operations.

## Application update only

Install the signed sequence-5 package through Software Updates to start the new local panel automatically. Existing settings, owner accounts and monitoring data are preserved. The [0.1.2-dev installer ISO](https://github.com/safin97/airlink-isp-os/releases/download/v0.1.2-dev/AirLink-ISP-OS-amd64.iso) remains the new-installation media; install it and then apply this update. No ISO is rebuilt or uploaded in this release.

Published as GitHub Latest for the existing signed update feed. This remains a development build: hardware/load qualification, automatic update rollback and full base-OS/kernel upgrades are not complete.
