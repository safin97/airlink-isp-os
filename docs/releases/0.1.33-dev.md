# AirLink ISP OS 0.1.33-dev

This update adds customer Telegram notifications, editable recharge messages and owner section visibility, and improves Deye Solar load readings.

- Configure the owner's Telegram bot for linked customers, or connect an owner Telegram account for phone lookup and customer notification tests. Bot delivery requires a customer to start and link the bot; account lookup depends on Telegram phone privacy and account restrictions.
- Send one notification after a confirmed card PIN, balance, extension, FIB or FastPay recharge. FIB/FastPay receipts require verified production payment. Messages include available service details, masked card numbers, expiry and the SAS4 manager recharge cost. Zero costs are shown; unavailable costs are omitted.
- Choose English, Kurdish/Badini or Arabic in Telegram account lookup for ISP card customer notifications. Edit and preview messages for each recharge type, tests, upcoming expiry and expired service. The recharge-cost placeholder uses the SAS4 manager cost; dates no longer display the Asia/Baghdad suffix.
- Optionally enable notifications for services expiring in three days and recently expired services. Delivery history reports sent, skipped, failed or unconfirmed outcomes. Ambiguous sends are not automatically repeated.
- Owners can choose which sections are visible to owner accounts while retaining full owner access. Existing manager access-role controls remain available.
- Deye Solar dashboard load shows watts and amps, distinguishing measured current from an estimate when applicable.

Install through Software Updates → Check again → Update now. This signed application update preserves existing accounts and settings and includes database migrations. Automatic customer notification features start disabled until configured. Existing sent messages are not changed or resent. Telegram credentials are encrypted; no personal credentials or publisher private keys are included in the release.

This is a development application update, without a new installer ISO or base-OS/driver upgrade. Deye data freshness still depends on inverter uploads and Deye Cloud. Telegram phone lookup cannot bypass privacy settings or guarantee that a phone number is discoverable.
