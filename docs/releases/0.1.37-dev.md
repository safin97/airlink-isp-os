# AirLink ISP OS 0.1.37-dev

Fixes the MEGA connection failure introduced by the Linux package in 0.1.36-dev. That package contained a distribution build of rclone without the MEGA backend, so connection tests failed before reaching MEGA and showed a misleading login/quota error.

- Bundles the official rclone 1.76.0 release, verified against a pinned SHA-256 checksum. Packaging now checks that the executable contains working MEGA backend support before accepting it.
- Checks MEGA backend availability at runtime. Missing support is reported as an installation problem rather than an account-password problem.
- Keeps saved MEGA credentials, backup passwords, schedules, existing backups, file recovery and Deye sharing unchanged.

Install through **Software Updates → Check again → Update now**, then open **Settings → Backups → MEGA cloud backup → Test MEGA connection**. You do not need to change your password to correct this packaging fault. A successful test enables backups and the saved weekly schedule.

This is a signed development application update with no database migration, new installer ISO or base-OS upgrade. Normal MEGA authentication, account restrictions, network access, storage and transfer quotas still apply after the transfer helper is corrected.
