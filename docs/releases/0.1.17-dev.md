# AirLink ISP OS 0.1.17-dev

- Online Users usernames open user information even when SAS4 omits the user ID. The account-scoped resolver matches the exact username.
- Online Users now includes Open device. It uses the saved Device API login assigned to the subscriber’s SAS4 manager, after verifying the current online username, IP and session.
- The read-only device panel shows wireless signal and SSID, Ethernet ports and link speed, and MikroTik REST PPPoE client details. Refresh keeps previous readings visible if a later request fails.
- Saved credentials remain encrypted on the server. Device and PPPoE passwords are never returned to the browser. HTTPS/HTTP follows the saved connection mode; rejected credentials do not trigger a downgrade retry.

MikroTik requires a reachable RouterOS REST API with read permissions. Supported Ubiquiti airOS devices expose signal, SSID and active Ethernet links; PPPoE details are unavailable through this adapter. Mimosa device API access is not implemented. Background customer telemetry remains SNMP-only. No device settings are changed by this panel.

This signed development application update includes the full application and source. No installer ISO, kernel or GPU drivers are updated. Install through Software Updates → Check again → Update now.
