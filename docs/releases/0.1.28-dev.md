# AirLink ISP OS 0.1.28-dev

Managers without personal monitoring settings now use the active owner's device monitoring settings for Online Users. This enables device type, Ethernet speed, signal and SSID readings when devices are reachable and provide those readings. Credentials remain server-side and manager customer lists and telemetry caches remain isolated. Existing personal settings take precedence.

This cumulative signed development application update includes 0.1.27-dev. No database migration is introduced. Install from Software Updates. This is not a kernel or base-OS upgrade.
