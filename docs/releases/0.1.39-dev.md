# AirLink ISP OS 0.1.39-dev

The Deye Solar dashboard now includes a **Grid downtime** calculator below the energy-flow diagram. It shows:

- Current observed grid outage duration.
- Total observed grid downtime and uptime.
- Unknown monitoring time and the date tracking began.

Counters use confirmed grid-voltage samples. Duplicate readings do not add time, and missing/stale cloud data or interrupted monitoring remain unknown. The current outage counter resets when the grid returns or observations become uncertain. Existing accumulated totals are preserved; current-outage tracking begins with new observations after upgrading.

Saved totals stay visible during cloud errors in live dashboard updates, while stale power values are hidden. Tracking continues in the background while AirLink runs, including when the browser is closed. Owners control configuration and sharing; authorized Wakil viewers see the same read-only figures.

This update requires no database migration and preserves monitoring data and settings. Both normal online updates and the signed `.airlink-update` download are provided. No installer ISO or base-OS update is included.
