# AirLink ISP OS 0.1.11-dev

This signed application update consolidates account permissions in Access Roles and simplifies the dashboard.

- Use Access Roles as the single account-type page. Add/Edit Account selects an access role directly; the separate Roles page is removed.
- Create reusable access roles with separate Read, Edit and Delete permissions for each supported section. Existing role names, assignments and permissions are migrated automatically.
- The owner can rename, edit permissions for, or delete Manager, Technician and Viewer. Reassign accounts before deleting a type. Owner remains protected with full access.
- Permission changes apply to existing accounts. Custom role permissions and existing inventory scopes remain separate; account administration and global place management remain owner-only.
- Show only PC Performance (CPU, memory, storage and disk activity) and Network Health on the main dashboard.
- Preserve accounts, assigned places, inventory, encrypted credentials, HTTPS and the signed update feed.

Install through Software Updates → Check again → Update now. This is a development application update. No installer ISO, kernel or GPU driver package is included.
