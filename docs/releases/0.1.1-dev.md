# AirLink ISP OS 0.1.1-dev

Development release with the new in-dashboard update workflow.

- Automatically checks the signed GitHub feed when the owner opens Software Updates and every five minutes while the page stays open.
- Shows the release, signature verification, size and release notes inside the dashboard.
- One confirmed **Update now** action downloads, verifies and installs the selected release without opening a new tab, with progress and reconnection during service restarts.
- Scheduling prepares and verifies the selected package first. Version/sequence and persisted hash/size approval prevent the installer switching to another release.
- Matching installed releases report up to date; install replay, signature failures and failed-installation safeguards remain enforced.
- The updated installer ISO includes the GitHub publisher configuration. Package upgrades restart the controller and console so their new code becomes active without waiting for a reboot.

## Downloads

Use `AirLink-ISP-OS-amd64.iso` for a new compatible x86_64 UEFI installation. Disable Secure Boot. Use the signed `.deb` and `stable.json` through the owner-only Update Center for an existing AirLink appliance. The configuration bundle is only needed by older unconfigured installations.

This remains a development build. Vendor wireless/client adapters, full base-OS/kernel upgrades, automatic rollback, and production hardware qualification are not complete. These are application updates, not a complete Linux distribution upgrade. See PROGRESS.md and RELEASE-VERIFICATION.md for evidence and limits.

This release is listed as GitHub Latest so the configured signed-update feed can find it. Installation remains owner-confirmed; publishing a release does not automatically install it.
