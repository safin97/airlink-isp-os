# AirLink artwork

The two original PNG files were supplied by the owner. Their colors, proportions and alpha channels are preserved.

- `airlink-horizontal.png`: dashboard navigation, startup screen, installer headers, GRUB theme and repository header.
- `airlink-stacked.png`: login/setup screen, compact mobile header, application/window icons.
- The browser favicon is an SVG viewport over the original stacked PNG's symbol; it does not redraw the artwork.

Graphical surfaces use a light background for the dark blue wordmark. The text-only Linux management/recovery terminals retain the AirLink name because they cannot display PNG logos. Copies under `frontend/assets/branding` and `frontend/web` ship the same original files with the dashboard.
